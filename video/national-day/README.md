# ريل اليوم الوطني العُماني · ٢٠ نوفمبر 🇴🇲

`zayana-national-day.mp4`: ريل عمودي 1080×1920، مدته 15 ثانية، 30 إطار في الثانية، فيه صوت، وجاهز للإنستغرام.
`cover.jpg`: صورة الغلاف.

| الثانية | المشهد |
|---|---|
| 0–2 | ضربات على الإيقاع: ٢٠ ← نوفمبر ← نبض القلب ← عُمان |
| 2–5 | شروق على الجبل الأخضر، المدرجات وورد يطير |
| 5–8 | قلعة وسفينة داو في بحر عُمان وقت الغروب |
| 8–11.5 | **الدروب**: علم عُمان يرفرف، وزيانه تنط ومعها علمها، مع قصاصات ملونة وقلوب |
| 11.5–15 | ألعاب نارية فوق مسقط: "كل عام وعُمان بخير" |

الموسيقى كلها مولّدة بالكود (`make_audio.py`): طبول بإيقاع خليجي، تصفيق، وعود على مقام الحجاز. ما فيها أي حقوق.

## إعادة التوليد
```bash
python3 make_audio.py          # يطلع audio.wav
node render.js out.mp4         # يحتاج Playwright و ffmpeg
```
تقدر تفتح `reel.html` في المتصفح وتشوف المعاينة مباشرة. ولو تبي تعدّل النصوص، تلقاها في دوال scene1 إلى scene5.

# ألبوم الجدّة 📖 (٢١ ثانية)

زيانه تفتح ألبوم جلد قديم مكتوب عليه "عُمان"، وجنبه مبخرة يطلع منها دخان اللبان. كل صفحة فيها صورة قديمة بالأبيض والأسود، وتتلوّن قدامك:
مطرح ← نزوى ← الجبل الأخضر ← رمال الشرقية ← صلالة ← صورة زيانه مع العلم. بعدها الكاميرا تدخل في الصورة الأخيرة، ويطلع الختام: "كل عام وعُمان بخير".

| الملف | الصوت |
|---|---|
| `zayana-album-silent.mp4` | بدون صوت، عشان تضيف الأغنية من مكتبة إنستغرام |
| `zayana-album-music.mp4` | موسيقى هادية مولّدة بالكود (`make_album_audio.py`) |

الختام (الثانية 17.1) مضبوط على **الثانية 0:36.7** من الأغنية، يعني لو بديت الأغنية من **0:19.6** ينزل الختام مع ضربتها.

```bash
python3 build_album.py                       # يبني album.html من album.src.html ومن الأجزاء المشتركة في reel.html
node render.js out.mp4 --page album.html --audio none
```
